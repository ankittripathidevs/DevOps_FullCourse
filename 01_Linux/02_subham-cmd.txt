(20) soft link:-
    . ln -s /home/ankit/userankit/linux/cloud.txt  softlink-fileHai
    
    . Soft link is the shortcut of actual(original path).
    . If original file is deleted → soft link will(deleted)
      break ho gaya (red in color)
    . change in original file will only reflect in softLink file
    
 (21) hard link:- 
     . ln /home/ankit/userankit/linux/cloud.txt hardlink-fileHai
     
    . Hard link is another name of the original file.
    . Both files share same data on disk.
    . If original file is deleted → hard link still works (data safe).
    . Changes in original file/anyfile → automatically reflect in hard link.
    . Hard link cannot be created for directories.
    
 (21) ls - ltr :- Breakdown

  t → Sort by modification time
  Newest files first (without r).
  r → Reverse order
  So it flips the sorting → Oldest files first.
