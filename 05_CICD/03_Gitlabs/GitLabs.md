#### 1 What is GitLab?
- GitLab is a platform where you can write code, manage it, and automatically deploy it — all in one place

- GitLab is an all-in-one DevOps platform that helps you:
- Store code (like GitHub)
- Collaborate with teams
- Automatically build, test, and deploy applications

👉 In simple words:
- GitLab = Git (code) + CI/CD (automation) + DevOps tools (everything in one place)


🔹 Core Idea
- Instead of using multiple tools like:
- GitHub (code)
- Jenkins (CI/CD)
- Docker Hub (images)

👉 GitLab gives everything in one platform

🔗 GitHub vs GitLab URL Structure

🟢 GitHub URL
- https://github.com/username/repo

👉 Meaning:
username → your account name
repo → your repository (project)

📌 Example:
https://github.com/ankit123/devops-project
👉 Stored directly under your account


🟡 GitLab URL
- https://gitlab.com/{group}/{project}

👉 Meaning:
group → organization / team / namespace
project → repository name

📌 Example:
https://gitlab.com/devops-team/app-project
👉 Stored inside a group (like a folder for projects)

🔥 Key Difference (Very Important)
| Platform | Structure       | Concept                 |
| -------- | --------------- | ----------------------- |
| GitHub   | `username/repo` | Individual-based        |
| GitLab   | `group/project` | Team/organization-based |


🧠 Easy Way to Remember
👉 GitHub = Personal repos
👉 GitLab = Group-based repos (more company-style)
