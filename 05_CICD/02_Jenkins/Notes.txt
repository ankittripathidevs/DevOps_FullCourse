# Ubuntu EC2 — Jenkins + Docker CI/CD

## Step 1 — Update & Upgrade

```bash
# Update package list
sudo apt update

# Upgrade installed packages
sudo apt upgrade -y
```

## Step 2 — Git

```bash
# Install Git
sudo apt install git -y

# Check Git version
git --version

# Configure Git
git config --global user.name "ankittripathidevs"
git config --global user.email "ankittripathi2k24@gmail.com"
```

## Step 3 — Node.js + npm (LTS)

```bash
# Install curl
sudo apt install curl -y

# Install NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# Reload shell
source ~/.bashrc

# Install Node.js LTS
nvm install --lts

# Check versions
node -v
npm -v
```

## Step 4 — Docker

```bash
# Install Docker
sudo apt install docker.io -y

# Check version
docker --version

# Start + enable Docker
sudo systemctl start docker
sudo systemctl enable docker

# Check Docker status
sudo systemctl status docker

# Allow current user to use Docker
sudo usermod -aG docker $USER
newgrp docker

# Test Docker
docker run hello-world
docker ps
```

## Step 5 — Docker Compose

```bash
# Install Docker Compose V2
sudo apt update
sudo apt install docker-compose-v2 -y

# Check version
docker compose version

# Start Compose application
docker compose up -d

# Stop Compose application
docker compose down
```

## Step 6 — Java

```bash
# Install Java 21
sudo apt install fontconfig openjdk-21-jre -y

# Check version
java --version
```

## Step 7 — Jenkins

```bash
# Add Jenkins repository key
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key

# Add Jenkins repository
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" \
https://pkg.jenkins.io/debian-stable binary/ | \
sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null

# Install Jenkins
sudo apt update
sudo apt install jenkins -y

# Start + enable Jenkins
sudo systemctl start jenkins
sudo systemctl enable jenkins

# Check Jenkins
sudo systemctl status jenkins
jenkins --version
```

## Step 8 — Jenkins Port 8080

```text
AWS EC2
→ Security Group
→ Inbound Rules
→ TCP 8080
```

Open:

```text
http://EC2_PUBLIC_IP:8080
```

Get initial password:

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

## Step 9 — Jenkins + Docker Permission

```bash
# Add Jenkins to Docker group
sudo usermod -aG docker jenkins

# Restart Jenkins
sudo systemctl restart jenkins

# Test Docker access
sudo -u jenkins docker ps

# Test Compose access
sudo -u jenkins docker compose version
```

## Step 10 — GitHub SSH

```bash
# Check existing SSH keys
ls -la ~/.ssh

# Create SSH key
ssh-keygen -t ed25519

# Show public key
cat ~/.ssh/id_ed25519.pub
```

Add public key:

```text
GitHub
→ Settings
→ SSH and GPG keys
→ New SSH key
```

Test connection:

```bash
ssh -T git@github.com
```
