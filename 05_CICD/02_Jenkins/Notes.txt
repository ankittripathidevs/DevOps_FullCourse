    Jenkins Dashboard

Step 2 — Configure GitHub Project

Inside the Jenkins job:

    General
    → GitHub project

Repository:

    https://github.com/ankittripathidevs/two-tier-flask-app.git

Step 3 — Pipeline Script

Go to:

    Pipeline
    → Definition: Pipeline script

Example pipeline:

    pipeline {

        agent any

        stages {

            // =========================
            // 1. Clone Source Code
            // =========================
            stage('Code Clone') {
                steps {
                    echo 'Cloning code from GitHub'

                    git branch: 'main',
                        url: 'https://github.com/ankittripathidevs/Expenses-Tracker-WebApp.git'
                }
            }

            // =========================
            // 2. Build Docker Image
            // =========================
            stage('Build') {
                steps {
                    echo 'Building Docker image'

                    sh 'docker build -t expenses-tracker-app .'
                }
            }

            // =========================
            // 3. Test
            // =========================
            stage('Test') {
                steps {
                    echo 'Testing the application'

                    // Add real tests here later
                }
            }

            // =========================
            // 4. Login + Push to Docker Hub
            // =========================
            stage('Push to Docker Hub') {
                steps {

                    withCredentials([
                        usernamePassword(
                            credentialsId: "DockerHub_Credentials",
                            usernameVariable: "DockerHub_User",
                            passwordVariable: "DockerHub_Pass"
                        )
                    ]) {

                        echo 'Logging in to Docker Hub'

                        sh '''
                            echo "$DockerHub_Pass" | docker login \
                            -u "$DockerHub_User" --password-stdin
                        '''

                        echo 'Tagging Docker image'

                        sh '''
                            docker image tag expenses-tracker-app:latest \
                            "$DockerHub_User"/expenses-tracker:latest
                        '''

                        echo 'Pushing Docker image'

                        sh '''
                            docker push \
                            "$DockerHub_User"/expenses-tracker:latest
                        '''
                    }
                }
            }

            // =========================
            // 5. Deploy
            // =========================
            stage('Deploy') {
                steps {
                    echo 'Deploying application'

                    sh 'docker compose up -d --build'
                }
            }
        }
    }

Step 8 — Use Jenkinsfile from GitHub

Instead of keeping the pipeline script inside Jenkins, create a file
named:

    Jenkinsfile

at the root of the GitHub repository.

Example:

    two-tier-flask-app/
    ├── Jenkinsfile
    ├── Dockerfile
    ├── docker-compose.yml
    ├── requirements.txt
    └── ...

Then configure Jenkins:

    Jenkins
    → ExpenseTracker-CICD
    → Configure
    → Pipeline

Change:

    Definition:
    Pipeline script

to:

    Pipeline script from SCM

Select:

    SCM: Git

Repository URL:

    https://github.com/ankittripathidevs/two-tier-flask-app.git

Branch:

    */main

Then:

    Save
    → Build Now

Jenkins will now read the pipeline directly from the Jenkinsfile in
GitHub.

Important Notes

-   DockerHub_Credentials is the Jenkins credential ID, not the Docker
    Hub password.
-   Use a Docker Hub Personal Access Token as the password.
-   Never hard-code the Docker Hub token inside the Jenkinsfile.
-   Jenkins needs permission to access Docker through the docker group.
-   */main is the Jenkins SCM branch specifier for the main branch.
-   A GitHub webhook triggers Jenkins after a push; it does not itself
    deploy code.
-   docker compose up -d --build only works if the deployment server has
    the required docker-compose.yml and application files available in
    the Jenkins workspace.
-   For production, expose Jenkins through HTTPS rather than an
    unsecured public HTTP endpoint.
