# 🌸 Docker Monitoring — Logs & Attach

## 1. Check Container Logs

View logs generated by a container:

```bash
docker logs containerName
```

Example:

```bash
docker logs flask-app
```

Use `docker logs` when you only want to view the container's application output and errors.

---

## 2. Attach to a Running Container

Connect your terminal to the container's main process:

```bash
docker attach containerName
```

Example:

```bash
docker attach flask-app
```

---

## 3. Attach Using `nohup`

Run `docker attach` in the background:

```bash
nohup docker attach containerName &
```

Example:

```bash
nohup docker attach flask-app &
```

### Meaning

```text
nohup
  → Keeps the command running even if the terminal closes

docker attach
  → Attaches to the container's main process

&
  → Runs the command in the background
```

---

## 4. Difference

```text
docker logs
    → View container logs

docker attach
    → Connect to the container's main process

nohup docker attach ... &
    → Attach in the background
```

For normal log monitoring, prefer:

```bash
docker logs flask-app
```

---

## 🎯 Quick Reference

```bash
# View logs
docker logs containerName

# Attach to container
docker attach containerName

# Attach in background
nohup docker attach containerName &
```
